# Accuracy audit notes (November 11, 2026)

Evidence for the claims the website makes. Source reviewed: EcoPrompt `projects/ecoprompt/ecopromptv2` (extension v10.1.2, last commit Aug 14, 2026) and Trophy Case `projects/trophy-case` (read-only).

## EcoPrompt (from extension source)
| Question | Finding |
|---|---|
| Permissions | `activeTab`, `tabs`, `storage`, `alarms`, `scripting`; host permission only for the telemetry endpoint. Content script runs on all http/https pages except Chrome Web Store, Google sign-in and Stripe checkout. |
| Collected locally | Page metrics (element count, mutation rate, transfer size, video/canvas present); tab URL/title used to label sites by hostname and detect AI platforms; rolling history (120 entries) plus daily rollups; local log of optimizer events (up to 1000); theme; random anonymous ID. |
| Sent to a server | **Yes.** Each Prompt Optimizer use POSTs an anonymous record to a Firebase Cloud Function (Firestore): random userId, eventId, timestamps, token/character counts, savings, mode, platform/source labels, extension version. |
| Prompt text / browsing sent? | No. The event is built from counts only. Optimization is rule-based and local. |
| Default / opt-out | `popup.js` sets `ecoPromptAnalyticsConsent = true` on first use. **No UI exists to change it.** The extension's own About tab says "No personal data leaves your browser" which conflicts with this. |
| Retention / deletion | None in code. "Clear History" removes local energy history only. No endpoint or schedule deletes uploaded records. |
| Cost | No paid features, no AI API calls, no usage limits in source. Store-listing price not verifiable from source. |

Website changes made: EcoPrompt page, School page and `ai-tools/power-tracker/privacy.html` now describe this accurately.
**Recommended extension fix (not done, outside this repo):** make the upload opt-in or add an off switch, fix the About-tab wording, publish a retention/deletion process, then update the website policy.
Also note: `firestore.rules` in that repo is the default open-until-2026-07-01 rule, which has now expired. Cloud Functions use the admin SDK so they are unaffected, but review the rules.

## Legal pages
The previous Privacy, Cookies and Terms pages were generic boilerplate that did not match the site: they described accounts, passwords, payments, subscriptions, Google Analytics cookies (`_ga`, `_gid`), session/CSRF cookies, a 30-day money-back guarantee and unverified `privacy@` / `legal@` mailboxes. The site sets no cookies (only a `theme` value in localStorage) and has no analytics. All three were rewritten to describe only verified behavior and use hello@learntav.com. **These are plain-language drafts, not legal advice. Have them reviewed.** They are generated by `scripts/build/pages_legal.py`.
